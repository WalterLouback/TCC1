# No Need to Lift a Finger Anymore? Assessing the Quality of Code Generation by ChatGPT

Liu, Zhihan; Tang, Yue; Luo, Xiapu; Zhou, Yonghui; Zhang, Liangfeng. "No need to lift a finger anymore? assessing the quality of code generation by ChatGPT," IEEE Transactions on Software Engineering, vol. 50, no. 4, pp. 1000-1015, 2024.

🔗 arXiv: [2308.04838](https://arxiv.org/abs/2308.04838)

## 1. Fichamento de Conteúdo

Este artigo conduz uma avaliação empírica sistemática abrangente da qualidade de geração de código pelo ChatGPT, analisando 4.066 programas gerados em duas linguagens populares (Java e Python) para 2.033 tarefas de programação. O estudo tem três objetivos principais: analisar a correção do ChatGPT em tarefas de geração de código e descobrir fatores que influenciam sua eficácia (dificuldade da tarefa, linguagem de programação, momento em que tarefas foram introduzidas e tamanho do programa); identificar e caracterizar potenciais problemas com a qualidade do código gerado pelo ChatGPT; e fornecer insights sobre como esses problemas podem ser mitigados. A metodologia utiliza o benchmark LeetCode contendo problemas de programação em múltiplos níveis de dificuldade, com avaliação automatizada através de casos de teste e análise manual de problemas de qualidade. Os resultados destacam que dos 4.066 programas gerados, 2.756 (67,8%) foram considerados corretos, 1.082 (26,6%) forneceram saídas incorretas e 228 (5,6%) não compilaram. O estudo identifica diversos problemas de qualidade no código gerado, incluindo tratamento inadequado de casos extremos, uso ineficiente de estruturas de dados, e lógica incorreta em cenários complexos. São fornecidas recomendações práticas para mitigar esses problemas, incluindo refinamento iterativo de prompts, verificação manual cuidadosa e uso de ferramentas complementares de análise estática.

## 2. Fichamento Bibliográfico

* _Code Correctness Rate_ (taxa de correção de código) mede a proporção de programas gerados que produzem saídas corretas para todos os casos de teste, alcançando 67,8% no estudo (métrica principal).
* _Task Difficulty Levels_ (níveis de dificuldade de tarefa) categorizam problemas de programação em fácil, médio e difícil, mostrando que desempenho do ChatGPT diminui significativamente com aumento de complexidade (fator de influência).
* _Edge Case Handling_ (tratamento de casos extremos) refere-se à capacidade do código gerado de lidar corretamente com entradas limite e situações especiais, área onde ChatGPT frequentemente falha (problema identificado).
* _LeetCode Benchmark_ é uma plataforma contendo milhares de problemas de programação algorítmica usados para avaliar capacidades de geração de código (dataset de avaliação).
* _Iterative Prompt Refinement_ (refinamento iterativo de prompts) é uma estratégia para melhorar qualidade do código gerado através de múltiplas interações com o modelo, fornecendo feedback progressivo (estratégia de mitigação).

## 3. Fichamento de Citações

* _"ChatGPT has emerged as a powerful tool in the field of code generation, offering automated source code generation based on given specifications."_
* _"Out of 4,066 programs generated by ChatGPT, 2,756 programs (67.8%) are deemed correct, 1,082 programs (26.6%) provide wrong outputs, and 228 programs (5.6%) fail to compile."_
* _"Task difficulty significantly affects ChatGPT's performance, with correctness dropping from 85.3% for easy tasks to 47.2% for hard tasks."_
* _"We identify several quality issues in ChatGPT-generated code, including inadequate handling of edge cases, inefficient use of data structures, and incorrect logic in complex scenarios."_
* _"Programs generated for Java show slightly better correctness (69.2%) compared to Python (66.4%), though differences are not statistically significant."_
* _"Our findings suggest that while ChatGPT demonstrates promising capabilities in code generation, developers should not rely on it blindly and must carefully review and test generated code."_
