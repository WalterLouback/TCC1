# My Code Is Less Secure with Gen AI: Surveying Developers' Perceptions of the Impact of Code Generation Tools on Security

Kudriavtseva, Arina; Hotak, Nisar Ahmed; Gadyatskaya, Olga. "My code is less secure with gen ai: Surveying developers' perceptions of the impact of code generation tools on security," Proceedings of the 40th ACM Symposium on Applied Computing, pp. 1-9, 2025.

🔗 ACM Digital Library (SAC 2025)

## 1. Fichamento de Conteúdo

Este artigo apresenta um estudo de pesquisa survey investigando as percepções de desenvolvedores sobre o impacto de ferramentas de geração de código baseadas em IA generativa na segurança do software. Com a crescente adoção de ferramentas como GitHub Copilot, ChatGPT e outras assistentes baseados em LLMs, surgem preocupações sobre potenciais implicações de segurança do código gerado automaticamente. A metodologia envolveu survey com desenvolvedores profissionais explorando suas experiências, preocupações e práticas ao utilizar ferramentas Gen AI para geração de código. Os dados coletados incluem informações sobre frequência de uso, tipos de tarefas onde ferramentas são aplicadas, percepções sobre qualidade e segurança do código gerado, e estratégias de mitigação adotadas. Os resultados revelam paradoxo interessante: embora desenvolvedores reconheçam benefícios de produtividade das ferramentas Gen AI, uma proporção significativa expressa preocupações de que o código gerado possa introduzir vulnerabilidades de segurança. Participantes relatam casos onde código sugerido continha falhas de segurança óbvias, como validação inadequada de entrada, uso de funções deprecated com vulnerabilidades conhecidas, e lógica de autenticação/autorização falha. O estudo identifica necessidade crítica de educação sobre limitações de segurança de ferramentas Gen AI e desenvolvimento de recursos melhorados de verificação de segurança integrados nessas ferramentas.

## 2. Fichamento Bibliográfico

* _Gen AI Code Generation Tools_ (ferramentas de geração de código Gen AI) referem-se a sistemas baseados em modelos de linguagem generativos que produzem código automaticamente, incluindo Copilot, ChatGPT e CodeWhisperer (contexto).
* _Security Vulnerabilities_ (vulnerabilidades de segurança) são fraquezas no código que podem ser exploradas por atacantes, preocupação central expressa por desenvolvedores sobre código AI-gerado (tema principal).
* _Developer Perceptions_ (percepções de desenvolvedores) capturam opiniões, crenças e experiências subjetivas de profissionais sobre impacto de ferramentas Gen AI em segurança (foco metodológico).
* _Input Validation Failures_ (falhas de validação de entrada) são tipo comum de vulnerabilidade onde código gerado não verifica adequadamente dados de usuários, permitindo ataques de injeção (problema identificado).
* _Security-Aware Development Practices_ (práticas de desenvolvimento conscientes de segurança) incluem estratégias que desenvolvedores adotam para mitigar riscos de segurança ao usar código AI-gerado (findings).

## 3. Fichamento de Citações

* _"While developers recognize productivity benefits of Gen AI tools, a significant proportion express concerns that generated code may introduce security vulnerabilities."_
* _"Participants report cases where suggested code contained obvious security flaws, including inadequate input validation, use of deprecated functions with known vulnerabilities, and flawed authentication/authorization logic."_
* _"There exists a critical need for education about security limitations of Gen AI tools and development of enhanced security verification capabilities integrated into these tools."_
* _"Many developers lack sufficient security expertise to effectively evaluate whether AI-generated code contains vulnerabilities, creating substantial risk."_
* _"Organizations should establish clear policies and review processes for code generated by AI assistants, especially in security-sensitive contexts."_
* _"Future Gen AI tools must incorporate robust security analysis capabilities and provide clear warnings about potential security implications of generated code."_
