# Evaluating AIGC Detectors on Code Content

Wang, Jian; Liu, Shangqing; Xie, Xiaofei; Li, Yi. "Evaluating AIGC detectors on code content," arXiv preprint arXiv:2304.05193, 2024.

🔗 arXiv: [2304.05193](https://arxiv.org/abs/2304.05193)

## 1. Fichamento de Conteúdo

Este artigo apresenta o primeiro estudo empírico avaliando detectores de conteúdo gerado por IA (AIGC) especificamente em conteúdo relacionado a código. Embora múltiplos detectores AIGC tenham sido desenvolvidos e avaliados em dados de linguagem natural, seu desempenho em conteúdo de código gerado por LLMs como ChatGPT permanecia inexplorado. A motivação surge do potencial de uso indevido do ChatGPT, especialmente em domínios educacionais e críticos de segurança. A metodologia envolve a criação de um dataset abrangente incluindo 492,5K amostras de conteúdo relacionado a código produzido pelo ChatGPT, abrangendo atividades populares de software como Q&A (115K), sumarização de código (126K) e geração de código (226,5K). O estudo avalia seis detectores AIGC, incluindo três comerciais e três de código aberto, além de conduzir estudo com humanos para comparar capacidades humanas de detecção com detectores automatizados. Os resultados indicam que detectores AIGC demonstram desempenho inferior em dados relacionados a código comparado com dados de linguagem natural. Fine-tuning pode melhorar desempenho do detector, especialmente para conteúdo dentro do mesmo domínio, mas generalização permanece um desafio. A avaliação humana revela que detecção por humanos também é bastante desafiadora, com acurácia variando significativamente entre participantes.

## 2. Fichamento Bibliográfico

* _AIGC Detectors_ (detectores de conteúdo gerado por IA) são ferramentas automatizadas projetadas para identificar se conteúdo foi produzido por modelos de IA ou humanos (conceito central).
* _Code-Related Content_ (conteúdo relacionado a código) engloba respostas Q&A, comentários de código, sumarizações de código e código-fonte gerado, diferenciando-se de texto natural (domínio de aplicação).
* _Fine-Tuning_ refere-se ao processo de adaptar detectores pré-treinados para domínios específicos através de treinamento adicional com dados relevantes (técnica de otimização).
* _Commercial vs Open-Source Detectors_ representam duas categorias de ferramentas avaliadas, com diferentes modelos de negócio e capacidades (taxonomia de ferramentas).
* _Human Detection Baseline_ estabelece capacidade humana de distinguir conteúdo AI-gerado como referência para avaliar desempenho de detectores automatizados (metodologia de validação).

## 3. Fichamento de Citações

* _"Despite its potential, the misuse of ChatGPT poses significant concerns, especially in education and safety-critical domains."_
* _"Numerous AIGC detectors have been developed and evaluated on natural language data. However, their performance on code-related content generated by ChatGPT remains unexplored."_
* _"Our results indicate that AIGC detectors demonstrate lower performance on code-related data compared to natural language data."_
* _"Fine-tuning can enhance detector performance, especially for content within the same domain; but generalization remains a challenge."_
* _"The human evaluation reveals that detection by humans is quite challenging, with accuracy varying significantly across participants."_
* _"Our findings highlight the need for developing specialized detection mechanisms for code-related AI-generated content."_
